NumPy Arrays · Chapter 11 — website folder

Upload EVERYTHING in this folder (index.html, pyodide/, video/, .nojekyll) to:
  - GitHub Pages: new public repository -> "Add file" -> "Upload files" -> drag all files ->
    Commit -> Settings -> Pages -> Source: "Deploy from a branch", branch "main", folder "/ (root)" -> Save.
    After ~1 minute the site is at https://<your-username>.github.io/<repository-name>/
  - Netlify Drop: drag this whole folder onto https://app.netlify.com/drop
  - Any web space: copy the folder as-is.

Do not open index.html by double-clicking: Python only runs when the site is served from a web address.
